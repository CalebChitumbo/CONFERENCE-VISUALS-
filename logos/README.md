# Logos

Drop the brand PNGs in this folder with **exactly these names** and the app
picks them up automatically (no upload needed):

| File | Used for |
|---|---|
| `conf_logo_transparent.png` | Conference logo on all dark display scenes (use the **transparent** 1024² version, never the white-background one) |
| `rpa_logo.png` | RPA institutional mark on the Title/Welcome scene host line |

Alternatively upload both once in the app under **Settings → Logos** — uploaded
logos are stored with the data and included in JSON exports, which is the most
portable option for the event laptop.

Brand rules (from the asset sheet): never recolour, rotate, skew or add effects
to either logo. Conference logo minimum 200px wide on screen, RPA logo minimum
64px wide.
